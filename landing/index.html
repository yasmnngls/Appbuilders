Local AI Interview Assistant

Notice. Follow up. Know when to move on.

A private, on-device interview assistant that helps Interviewers notice moments worth exploring, suggests neutral follow-up questions, re-observes what happens, and helps them know when to move on.

Watch demo View on GitHub Run it locally

For Interviewers · Vision and language models run on-device · No scores, no verdicts

The problem

An Interviewer is doing six jobs at once.

  • Too much to hold. Listening, understanding the answer, remembering the Question, deciding what to ask next, keeping the conversation moving and taking notes.
  • Useful moments slip by. A long look away or a reading-like pattern can be worth a gentle follow-up, but it is easy to miss while you are listening.
  • Monitoring tools over-judge. Proctoring software turns observations into scores and labels. Interviewers need a prompt to ask a better question, not a verdict.

How it works

A bounded follow-up loop that knows when to stop.

Gazewise learns each Candidate's own baseline first, then compares against it. Rules decide when a moment is worth exploring; a local language model only writes the note and the suggested question. You stay in control the whole time.

  1. 1

    Observe

    On-device vision tracks gaze, head pose and faces in view, compared with the Candidate's own baseline.

  2. 2

    Explore

    When a pattern holds up, you see a Moment worth exploring with one neutral follow-up you can ask, or not.

  3. 3

    Re-observe

    After you ask, it quietly watches whether the pattern continues.

  4. 4

    Resolve

    The observation settles, or one final follow-up is offered. Never more than two per Question.

  5. 5

    Move On

    It stops suggesting and gets out of the way, so you can get to the next Question.

What it is not

An assistant, not surveillance.

Gazewise reports observable patterns and leaves every judgment to the Interviewer. It does not decide whether a Candidate is cheating, lying, dishonest, suspicious or uncomfortable.

  • No Candidate score. No ratings, rankings or risk meters.
  • No cheating or honesty probability. It never labels deception or a violation.
  • No emotion reading. It does not infer discomfort, stress or mood.
  • No face recognition. It counts faces in view; it never identifies anyone.
  • No hiring recommendation. Hiring decisions stay with people.
  • No automatic questions. It suggests; only the Interviewer asks.

Why local AI

The AI runs on the Interviewer's laptop.

Candidate video stays put

Face and eye data is sensitive. Each frame is analysed in memory on the laptop and discarded. No upload, no stored footage, no images in the report.

Real time, no upload

Gaze analysis needs a steady stream of frames. On-device, there is no round trip to a server and no per-call cost.

No cloud AI needed

Vision runs in the browser and the language model runs through Ollama on localhost. The core AI loop keeps working with no cloud AI service.

The interview platform may use the internet. Our AI analysis layer does not need the cloud.
A Flag is an observation, never a verdict.

Architecture at a glance

Rules detect. The language model only writes.

  • Video comes from the meeting window or a local webcam.
  • Local vision (MediaPipe Face Landmarker, in the browser) turns frames into signals: face count, head pose, gaze.
  • Baseline, rules and an evidence gate decide when a pattern is worth exploring. Plain, unit-tested TypeScript.
  • The local LLM (Ollama on localhost) writes a neutral note and follow-up. It never sees video, only structured context.
  • The Interviewer decides: ask, continue or move on.

Run it locally

Four commands on your own laptop.

Requirements

  • Node.js 20 or newer
  • Chrome or Edge (Chromium-based browser)
  • Ollama, installed locally

Full steps, including picking the Candidate tile in a meeting window, are in the README. 

# 1. Get the local language model
ollama pull qwen2.5:3b
# 2. Get the code
git clone <repository-url> gazewise && cd gazewise
# 3. Install
npm install
# 4. Start, then open http://localhost:5173
npm run dev

The face model and its runtime ship with the repository, so the app loads without a network connection.

What it is built with.

Models
MediaPipe Face Landmarker (face_landmarker.task, float16, Google), run in the browser. Qwen2.5 3B Instruct (qwen2.5:3b) via Ollama.
Frameworks and libraries
@mediapipe/tasks-vision, React, Vite, TypeScript, Tailwind CSS, Vitest.
APIs and cloud services
None at runtime for the core AI loop. The Ollama HTTP API is on localhost. The interview platform itself (if used) is the only part that needs the internet.
AI development tools
Claude Code.
